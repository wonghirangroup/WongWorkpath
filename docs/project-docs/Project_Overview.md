# Project Overview

## โมดูลหลักของระบบ (ตรงกับเมนู Sidebar 8 รายการ)

| # | เมนู | เส้นทาง (route) | สรุปหน้าที่ |
|---|---|---|---|
| 1 | แดชบอร์ด | `/dashboard` | ภาพรวมโครงการ งบประมาณ สัดส่วนสถานะ งานของฉันที่ใกล้ครบกำหนด, Export CSV/PDF |
| 2 | จัดการงานและโครงการ | `/tasks` | รายการโครงการ → รายละเอียดโครงการ (ภาพรวม/งาน/ทีม/การประชุม/Gantt) → รายละเอียดงาน |
| 3 | ปฏิทินและตารางเวลา | `/calendar` | ปฏิทินรวมงาน/นัดประชุม/โครงการ กรองได้หลายแบบ |
| 4 | งานของฉัน | `/gantt` (ชื่อ route เดิม แต่ไม่ใช่ Gantt chart แบบเก่าแล้ว) | งานของฉัน / งานที่ต้องตรวจ / รออนุมัติจากฉัน / โครงการของฉัน / Gantt ของฉัน |
| 5 | เอกสาร Drive | `/docs` | โฟลเดอร์/ไฟล์/ลิงก์ ส่วนตัวหรือผูกกับโครงการ |
| 6 | คลังรหัสผ่าน | `/vault` | เก็บรหัสผ่าน/API key/บัญชีธนาคาร/token ขอบเขตส่วนตัว/ทีม/โครงการ |
| 7 | จัดการพนักงาน | `/employees` | รายชื่อพนักงาน, โครงสร้างองค์กร, บันทึกกิจกรรม (Log) |
| 8 | การตั้งค่า | `/settings` | โปรไฟล์, เปลี่ยนรหัสผ่าน, เปิด/ปิดการแจ้งเตือน |

`/dashboard` และ `/settings` เปิดให้ทุกบัญชีเสมอ ระดับสิทธิ์จำกัดเมนูรายคนไม่ได้ 2 เมนูนี้

## บทบาทผู้ใช้และขอบเขตสิทธิ์ (สรุปย่อ — รายละเอียดเต็มอยู่ใน SRS.md)

ระบบมี 4 ระดับบัญชี (`AccountType`): `employee | admin | superadmin | executive`

| เรื่อง | พนักงาน | Admin | Super Admin | ผู้บริหาร |
|---|---|---|---|---|
| โครงการ/งานที่เห็นโดยตั้งต้น | ของฉัน (สลับ "ทั้งหมด" ได้) | เหมือนพนักงาน | เหมือนพนักงาน | ทั้งหมดทันที |
| แก้ไขโครงการ/งาน | เจ้าของ/ผู้รับผิดชอบแก้ตรง คนอื่นขออนุมัติ | เหมือนพนักงาน | เหมือนพนักงาน | แก้ตรงได้ทุกอัน |
| ลบโครงการ | ❌ | เจ้าของลบตรง/คนอื่นขออนุมัติ | เหมือน Admin | ลบตรงได้ |
| จัดการบัญชีพนักงาน | ❌ | เพิ่ม/แก้ไข/ลบเฉพาะระดับพนักงาน | ทุกระดับ | ทุกระดับ |
| แก้ไขโครงสร้างองค์กร | ❌ (ดูได้) | ❌ (ดูได้) | ✅ | ✅ |
| ดูบันทึกกิจกรรม (Log) | ❌ | ✅ | ✅ | ✅ |
| กำหนดระดับสิทธิ์ผู้ใช้ | ❌ | ❌ | ✅ | ✅ |

Super Admin เป็น **singleton** มีได้คนเดียวในระบบ (ตั้งคนใหม่แล้วคนเดิมถูกลดเป็น Admin อัตโนมัติ) ผู้บริหารมีได้ **ไม่เกิน 2 คน**

## เทคโนโลยีหลัก

- **Frontend:** React 19 + TypeScript + Vite 6 + Tailwind CSS v4 + React Router v7 + Motion + Lucide
- **Backend:** Express 4 + MySQL (mysql2) + bcryptjs + Resend
- **Auth:** token แบบ HMAC-SHA256 ที่เซิร์ฟเวอร์เซ็นเอง (ไม่ใช้ library JWT มาตรฐาน แต่ทำหน้าที่เดียวกัน) อายุ 30 วัน เก็บใน `localStorage`

รายละเอียดเพิ่มเติมอยู่ใน [Development_Environment.md](./Development_Environment.md)

## สิ่งที่ยังไม่ได้ทำ / เป็นข้อจำกัดที่รู้อยู่แล้ว

- ไม่มีชุดทดสอบอัตโนมัติ (unit/integration test) ในโปรเจกต์ — ดู [Test_Cases.md](./Test_Cases.md) สำหรับชุดทดสอบมือที่ใช้อยู่
- การสร้าง/แก้ไข/ลบงาน (project task) ยังไม่ถูกบันทึกลงบันทึกกิจกรรม (Log) — มีแค่โครงการ/เอกสาร/พนักงาน/ล็อกอิน/นัดประชุม/โครงสร้างองค์กร/คำขออนุมัติ
- คลังรหัสผ่านไม่มีการเข้ารหัสข้อมูลระดับแอป (ไม่มี PIN ชั้นที่สอง) ความปลอดภัยอยู่ที่การกรองสิทธิ์ฝั่งเซิร์ฟเวอร์เท่านั้น — เป็นการตัดสินใจของทีมแล้ว ไม่ใช่บั๊ก
- Dashboard, ปฏิทิน, และ "งานของฉัน" ยังไม่ผ่านการออกแบบรอบใหม่ให้ตรงกับ design system ที่เหลือทั้งระบบ (ดู `Design.md` ที่ root ของ repo)
