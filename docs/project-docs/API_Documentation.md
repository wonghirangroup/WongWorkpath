# API Documentation

Base URL: `https://wongworkpath.onrender.com` (production) หรือ `http://localhost:4000` (เครื่องพัฒนา)

ดึงรายการ endpoint ทั้งหมดจากโค้ด `server/routes/*.ts` และการ mount ใน `server/index.ts` จริง (2569-09-25) ไม่มี endpoint อื่นนอกจากที่ระบุในเอกสารนี้

## การยืนยันตัวตน (Authentication)

ทุก endpoint ใต้ `/api` ต้องแนบ header `Authorization: Bearer <token>` **ยกเว้น 5 เส้นทางนี้เท่านั้น**:

- `GET /api/health`
- `POST /api/auth/login`
- `POST /api/auth/forgot-password`
- `POST /api/auth/verify-otp`
- `POST /api/auth/reset-password`

Token ได้จากการล็อกอินสำเร็จ อายุ 30 วัน เซ็นด้วย HMAC-SHA256 (`server/lib/auth.ts`) เซิร์ฟเวอร์ตรวจ token แล้ว **เขียนทับ** `actorEmployeeId`/`decidedBy`/`requestedBy` ที่ client ส่งมาด้วยตัวตนจริงจาก token เสมอ — client ปลอมตัวตนไม่ได้ ไม่ว่าจะส่งค่าอะไรมาในคำขอ

## GET /api/health

ไม่ต้องล็อกอิน — เช็คสถานะเซิร์ฟเวอร์และการเชื่อมต่อฐานข้อมูล คืน `{ status: 'ok', db: 'connected' }`

## /api/auth — การยืนยันตัวตน

| Method | Path | คำอธิบาย |
|---|---|---|
| POST | `/login` | เข้าสู่ระบบด้วย username+password คืน `{ token, employee }` มีการจำกัดจำนวนครั้งผิด (rate limit) |
| GET | `/me` | (ต้อง auth) ข้อมูลบัญชีปัจจุบัน — ใช้ restore session ตอนโหลดหน้าใหม่ |
| POST | `/forgot-password` | ขอ OTP ส่งไปอีเมลที่ผูกกับบัญชี |
| POST | `/verify-otp` | ยืนยัน OTP คืน `resetToken` (อายุ 10 นาที) |
| POST | `/reset-password` | ตั้งรหัสผ่านใหม่ ต้องแนบ `resetToken` |

## /api/employees — พนักงาน

| Method | Path | สิทธิ์ | คำอธิบาย |
|---|---|---|---|
| GET | `/` | ทุกคน | รายชื่อพนักงานทั้งหมด |
| POST | `/` | Admin ขึ้นไป | สร้างบัญชีใหม่ (Admin ตั้งได้แค่ระดับ employee) |
| PUT | `/:id` | ดูเงื่อนไข | แก้ข้อมูลพนักงาน — พนักงานทั่วไปแก้ได้เฉพาะฟิลด์ตัวเอง (รูป/เบอร์/ที่อยู่/อีเมล/แจ้งเตือน/รหัสผ่าน) ชื่อ-ชื่อเล่นของตัวเองต้องผ่านคำขออนุมัติ |
| PUT | `/:id/password` | เจ้าของบัญชีเท่านั้น | เปลี่ยนรหัสผ่านตัวเอง จำกัดวันละ 1 ครั้ง |
| DELETE | `/:id` | Admin ขึ้นไป (ไม่ลบตัวเองได้) | ลบบัญชี — Admin ลบได้เฉพาะระดับ employee |

## /api/projects — โครงการ

| Method | Path | คำอธิบาย |
|---|---|---|
| GET | `/` | โครงการทั้งหมด (การกรอง "ของฉัน"/"ทั้งหมด" ทำที่ฝั่งไคลเอ็นต์) |
| POST | `/` | สร้างโครงการ — รับ `createFolderName` เพื่อสร้างโฟลเดอร์ Drive พร้อมกันในธุรกรรมเดียว คืน `createdFolder` ถ้ามี |
| PUT | `/:id` | แก้ไข — มีเจ้าของแล้วต้องเป็นเจ้าของหรือผู้บริหารเท่านั้น คนอื่นได้ 409 พร้อม `requiresApproval: true` |
| DELETE | `/:id` | ลบ — **จำกัดเฉพาะ Admin ขึ้นไปเท่านั้น** (403 สำหรับพนักงานทั่วไปแม้เป็นเจ้าของ) แล้วตรวจสิทธิ์เจ้าของต่อว่าลบตรงได้หรือต้องขออนุมัติ ลบแล้ว cascade ไปยังงาน เอกสาร คำขออนุมัติที่เกี่ยวข้อง |

## รูปแบบข้อผิดพลาด (Error Response)

ทุก endpoint ที่ล้มเหลวคืน JSON รูปแบบ `{ "message": "ข้อความภาษาไทยอธิบายปัญหา" }` พร้อม HTTP status ที่เหมาะสม:

| Status | ความหมาย |
|---|---|
| 400 | ข้อมูลที่ส่งมาไม่ถูกต้อง/ไม่ครบ |
| 401 | ไม่ได้ล็อกอิน หรือ token หมดอายุ |
| 403 | ล็อกอินแล้วแต่ไม่มีสิทธิ์ทำสิ่งนั้น |
| 404 | ไม่พบรายการ (รวมถึงรายการที่มีจริงแต่ผู้เรียกไม่มีสิทธิ์เห็น) |
| 409 | ขัดแย้งกับสถานะปัจจุบัน (เช่น ต้องขออนุมัติก่อน, มีคำขอ pending อยู่แล้ว, ลบไม่ได้เพราะยังมีตัวอ้างอิงอยู่) |
| 429 | ล็อกอินผิดเกินจำนวนที่กำหนด |
| 500 | ข้อผิดพลาดฝั่งเซิร์ฟเวอร์ |
