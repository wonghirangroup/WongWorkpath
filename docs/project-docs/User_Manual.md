# คู่มือการใช้งาน (User Manual)

คู่มือนี้เขียนสำหรับพนักงานที่ใช้งานระบบ Wong Workpath ในชีวิตประจำวัน ไม่ต้องมีความรู้ด้านเทคนิค

## เข้าสู่ระบบ

1. เปิดเว็บ `wong-workpath.vercel.app`
2. กรอก **Username** และ **รหัสผ่าน** ที่ได้รับจากแอดมิน กด "เข้าสู่ระบบ"
3. ถ้าลืมรหัสผ่าน กด **"ลืมรหัสผ่าน"** → กรอกอีเมลที่ผูกกับบัญชี → ระบบส่งรหัส OTP ไปทางอีเมล → กรอกรหัสยืนยัน → ตั้งรหัสผ่านใหม่

> หมายเหตุ: ถ้าไม่ได้ใช้ระบบนานหลายนาที เว็บอาจโหลดช้าครั้งแรก 30-60 วินาที เป็นเรื่องปกติของระบบฝั่งเซิร์ฟเวอร์ ไม่ใช่ปัญหาที่ตัวเครื่อง

## แดชบอร์ด (หน้าแรก)

เห็นภาพรวมโครงการ งบประมาณรวม สัดส่วนสถานะโครงการ และงานของตัวเองที่ใกล้ครบกำหนด กดปุ่ม **"Export"** มุมขวาบนเพื่อดาวน์โหลดรายงานเป็น CSV หรือ PDF

## จัดการงานและโครงการ

1. **สร้างโครงการใหม่:** กดปุ่ม "สร้างโครงการใหม่" → กรอกชื่อ เลือกประเภท → ตั้งค่าผู้รับผิดชอบ/วันที่ (ไม่บังคับ) → ตรวจสอบข้อมูล → กด "สร้างโครงการ"
2. **เข้าดูโครงการ:** คลิกที่ชื่อโครงการในรายการ จะเห็น 5 แท็บ: ภาพรวม, งาน, ทีม, การประชุม, Gantt
3. **เพิ่มงาน:** ในแท็บ "งาน" กด "เพิ่มงาน/นัดประชุม" → กรอกชื่องาน เลือกผู้รับผิดชอบ/ผู้ตรวจ วันที่ → กด "เพิ่มงาน"
4. **ส่งงาน:** เมื่อทำงานเสร็จ กดปุ่มรูปกระดาษเครื่องบิน "ส่งงาน" ที่แถวงานนั้น → เลือกผู้ตรวจ เขียนบันทึก แนบไฟล์ (ถ้ามี) → กด "ส่งงาน"
5. **ตรวจงาน (สำหรับผู้ตรวจ):** เมื่อมีงานรอตรวจ จะได้รับการแจ้งเตือน กดเข้าไปอ่านบันทึกที่แนบมา แล้วเลือก "ผ่าน" หรือ "ตีกลับ" (ตีกลับต้องระบุเหตุผล)
6. **ขอแก้ไข/ลบงานของคนอื่น:** ถ้าไม่ใช่ผู้รับผิดชอบของงาน/โครงการนั้น การแก้ไข/ลบจะกลายเป็น "คำขอ" ที่ต้องให้ผู้รับผิดชอบอนุมัติก่อน

## ปฏิทินและตารางเวลา

ดูงาน/นัดประชุม/โครงการรวมในปฏิทินเดียว กรองได้ที่แถบด้านบน: ทั้งหมด/เฉพาะกำหนดส่งงาน/เฉพาะนัดประชุม/เฉพาะโครงการ และสลับดู "ของฉัน"/"ทั้งบริษัท" ได้

## งานของฉัน

พื้นที่ทำงานส่วนตัว รวมงาน/โครงการของตัวเองจากทุกโครงการไว้ที่เดียว มี 5 แท็บ: งานของฉัน, งานที่ต้องตรวจ, รออนุมัติจากฉัน, โครงการของฉัน, Gantt ของฉัน

## เอกสาร Drive

เก็บไฟล์/โฟลเดอร์/ลิงก์ แบ่งเป็นส่วนตัว (เห็นคนเดียว) กับผูกกับโครงการ (เห็นทั้งทีมของโครงการนั้น) สร้างโฟลเดอร์ ลากไฟล์เข้าไปจัดหมวดหมู่ได้

## คลังรหัสผ่าน

เก็บรหัสผ่าน/API key/บัญชีธนาคาร/token ที่ใช้งานร่วมกัน แบ่งขอบเขต 3 แบบ: **ส่วนตัว** (เห็นคนเดียว), **ทีม** (เห็นทั้งแผนกตัวเอง), **โครงการ** (เห็นเฉพาะคนในโครงการนั้น) — ไม่มี PIN ชั้นที่สอง การล็อกอินหลักของระบบคือการป้องกันเดียว จึงไม่ควรใช้บัญชีร่วมกับผู้อื่น

## จัดการพนักงาน (สำหรับ Admin ขึ้นไป)

- **รายชื่อพนักงาน:** เพิ่ม/แก้ไข/ลบบัญชี พนักงานทั่วไปเห็นแค่รายชื่ออ่านอย่างเดียว
- **โครงสร้างองค์กร:** ดูผังฝ่าย/แผนก (แก้ไขได้เฉพาะ Super Admin/ผู้บริหาร)
- **บันทึกกิจกรรม (Log):** ประวัติการกระทำสำคัญทั้งหมดในระบบ ค้นหา/กรองตามวันที่ แผนก การกระทำได้ (Admin ขึ้นไปเท่านั้นที่เห็น)

## การตั้งค่า

- **โปรไฟล์:** แก้ไขรูป เบอร์โทร ที่อยู่ อีเมล (ชื่อ-ชื่อเล่นต้องขอ Admin อนุมัติ)
- **เปลี่ยนรหัสผ่าน:** เปลี่ยนได้วันละ 1 ครั้ง
- **การแจ้งเตือน:** เปิด/ปิดหมวดแจ้งเตือนแต่ละประเภทได้เอง

## ตั้งเตือนกำหนดส่งงาน/สิ้นสุดโครงการ

ในหน้ารายละเอียดงานหรือโครงการ กดที่ช่อง "เตือนฉันก่อนกำหนด" เลือกช่วงเวลาที่ต้องการ (1 วัน, 3 วัน, 7 วัน, 1 เดือน, 3 เดือน หรือกำหนดเอง) เป็นการตั้งค่าส่วนตัวของแต่ละคน ไม่กระทบคนอื่น บันทึกทันทีไม่ต้องรออนุมัติ
