# Introduction

## ระบบนี้คืออะไร

**Wong Workpath** เป็นเครื่องมือภายในบริษัท (internal tool) สำหรับบริหารจัดการงานประจำวันขององค์กร ครอบคลุม:

- การจัดการโครงการและงาน (project & task management)
- ปฏิทินและตารางเวลา รวมนัดประชุม
- พื้นที่ทำงานส่วนตัว ("งานของฉัน") ที่รวมงาน/โครงการของแต่ละคนข้ามหลายโครงการ
- คลังเอกสารกลาง (Drive) แบบมีโฟลเดอร์/ไฟล์/ลิงก์
- คลังรหัสผ่านองค์กร (credential vault) แบ่งขอบเขตส่วนตัว/ทีม/โครงการ
- การจัดการบัญชีพนักงานและโครงสร้างองค์กร (ฝ่าย/แผนก)
- ระบบแจ้งเตือนและบันทึกกิจกรรม (audit log)

ชื่อในโค้ดบางจุดยังหลงเหลือชื่อเดิมของโปรเจกต์คือ **"UnitySpace"** (เช่น คีย์ localStorage ขึ้นต้นด้วย `unityspace_*` และคำในข้อความ audit-log) เนื่องจากเปลี่ยนชื่อแบรนด์ภายหลังโดยไม่ได้ไล่แก้ทุกจุด ไม่กระทบการทำงานของระบบ

## ทำไมถึงสร้างระบบนี้

ก่อนหน้านี้บริษัทไม่มีเครื่องมือกลางสำหรับติดตามโครงการ/งาน ทำให้ข้อมูลกระจัดกระจาย (แชท, ไฟล์แชร์, ความจำคน) Wong Workpath ถูกสร้างขึ้นเพื่อรวมทุกอย่างไว้ในที่เดียว ให้ผู้บริหารเห็นภาพรวมทั้งบริษัท และให้พนักงานติดตามงานของตัวเองได้ชัดเจน พร้อมมีการควบคุมสิทธิ์การเข้าถึงข้อมูลตามบทบาท

## ใครใช้งานระบบนี้

พนักงานทุกคนในบริษัทใช้งานระบบนี้จริงทุกวัน ผ่าน 4 ระดับสิทธิ์ (ดูรายละเอียดเต็มใน [Project_Overview.md](./Project_Overview.md)):

| ระดับ | สรุปสั้นๆ |
|---|---|
| พนักงานทั่วไป (employee) | ผู้ใช้งานทั่วไป ทำงาน ส่งงาน ใช้เครื่องมือทุกอย่างในขอบเขตของตัวเอง |
| Admin | จัดการบัญชีพนักงาน (ระดับพนักงานทั่วไปเท่านั้น), ดูบันทึกกิจกรรม |
| Super Admin | มีได้คนเดียวในระบบ ดูแลระบบระดับสูงสุด กำหนดสิทธิ์ผู้ใช้ทุกระดับ แก้โครงสร้างองค์กร |
| ผู้บริหาร (executive) | มีได้ไม่เกิน 2 คน เห็นภาพรวมทุกโครงการทั้งบริษัท ข้ามขั้นตอนขออนุมัติได้ |

## สถานะปัจจุบัน

ระบบใช้งานจริง (production) แยกจากเครื่องพัฒนาแล้ว:

- **Frontend:** `wong-workpath.vercel.app` (Vercel, auto-deploy จาก branch `main`)
- **Backend:** `wongworkpath.onrender.com` (Render, แพลนฟรี, auto-deploy จาก branch `main`)
- **ฐานข้อมูล:** MySQL หนึ่งตัว ใช้ร่วมกันระหว่าง Render และเครื่องพัฒนาทุกเครื่อง

การ push โค้ดขึ้น branch `main` คือการขึ้นระบบจริงทันที รายละเอียดวิธี deploy อย่างปลอดภัยอยู่ใน [Setup_Deployment_Guide.md](./Setup_Deployment_Guide.md)
