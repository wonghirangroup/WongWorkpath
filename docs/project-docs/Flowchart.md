# Flowchart — ผังขั้นตอนการทำงานหลัก

ทุกไดอะแกรมในไฟล์นี้สร้างจากการอ่านโค้ดจริง (ไม่ใช่การออกแบบล่วงหน้า) และผ่านการ render ทดสอบด้วย Mermaid จริงแล้วทุกภาพ

## 1. เข้าสู่ระบบ / ลืมรหัสผ่าน

```mermaid
flowchart LR
    START(["เปิดหน้า Login"])
    A1["กรอก username + password"]
    A2{"ข้อมูลถูกต้อง?"}
    ERR1["ขึ้นข้อความผิดพลาด<br/>ฟอร์มยังเปิด"]
    RATE["ล็อกอินผิดเกิน 5 ครั้ง/15 นาที ต่อ IP+username<br/>หรือ 30 ครั้ง/15 นาทีรวมต่อ IP<br/>ปฏิเสธชั่วคราว (HTTP 429)"]
    A3["ระบบออก token อายุ 30 วัน<br/>เก็บใน localStorage"]
    A4["โหลดข้อมูลทุกโดเมน แล้วเข้าหน้าแดชบอร์ด"]
    DONE(["เข้าสู่ระบบสำเร็จ"])

    FORGOT["กด 'ลืมรหัสผ่าน'"]
    F1["กรอกอีเมลที่ผูกกับบัญชี"]
    F2["ระบบส่ง OTP ทางอีเมล ผ่าน Resend"]
    F3["กรอก OTP ยืนยัน"]
    F4{"OTP ถูกต้อง<br/>และยังไม่หมดอายุ ภายใน 10 นาที?"}
    F5["ตั้งรหัสผ่านใหม่"]
    FERR["ขึ้นข้อความผิดพลาด กรอกใหม่ได้"]
    FDONE(["ตั้งรหัสผ่านใหม่สำเร็จ กลับไปหน้า Login"])

    START --> A1 --> A2
    A2 -->|"ไม่ถูกต้อง"| ERR1 --> A1
    A2 -->|"ผิดเกินจำนวน"| RATE
    A2 -->|"ถูกต้อง"| A3 --> A4 --> DONE
    START -.-> FORGOT --> F1 --> F2 --> F3 --> F4

    F4 -->|"ถูกต้อง"| F5 --> FDONE

    classDef terminal fill:#272220,stroke:#272220,color:#ffffff

```

**ที่ตรวจกับโค้ดแล้ว:** `POST /api/auth/login`, `POST /api/auth/forgot-password`, `POST /api/auth/verify-otp`, `POST /api/auth/reset-password` เป็น 4 endpoint เดียวที่เปิดให้เรียกได้โดยไม่ต้องมี token (นอกจาก `/api/health`)
